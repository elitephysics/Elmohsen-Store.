# المحسن ستور v3 — نسخة مُراجعة

تمت مراجعة ملفات النسخة وإصلاح عدة مشاكل في الواجهة والمنطق:
- تحسين تسجيل الدخول وإنشاء الحساب والتحقق من البريد وكلمة المرور.
- التعامل مع تفعيل تأكيد البريد في Supabase بدل افتراض تسجيل الدخول مباشرة.
- التحقق من وجود مستخدم قبل فتح صفحة إتمام الطلب.
- التحقق من السلة والبيانات المطلوبة قبل إنشاء الطلب.
- منع عرض اسم المنتج داخل HTML بطريقة تسمح بحقن HTML بسيط.
- منع اعتبار الدفع الإلكتروني "تم" قبل وجود بوابة دفع حقيقية.
- تحسين التعامل مع أخطاء إنشاء عناصر الطلب.
- إضافة حالة واضحة للنجاح والخطأ.
- جعل طريقة الشحن المحفوظة متوافقة مع الاختيار المجاني/العادي.

## مهم جدًا قبل النشر
1. ضع مفتاح Supabase Publishable/Anon الحقيقي في `config.js`.
2. تأكد من وجود جداول `orders` و`order_items` و`shipments` والأعمدة المستخدمة في الكود.
3. فعّل Row Level Security (RLS) في Supabase واكتب سياسات مناسبة؛ وجود Publishable/Anon key في المتصفح طبيعي، لكن لا يجب أن تكون قاعدة البيانات مفتوحة للكتابة للجميع.
4. أسعار السلة القادمة من `localStorage` يمكن للمستخدم تعديلها من المتصفح. لذلك لا تعتمد على `unit_price` أو `total` القادمة من المتصفح في متجر حقيقي. الأفضل أن يكون إنشاء الطلب عبر RPC/Edge Function يعيد قراءة أسعار المنتجات من جدول المنتجات على الخادم.
5. الدفع الإلكتروني ما زال غير مفعّل. لا تضع Secret Key لأي بوابة دفع داخل HTML أو JavaScript.
6. ملفات هذه الحزمة لا تحتوي على `supabase.sql` أو ملفات المنتجات/الصفحة الرئيسية، لذلك لا يمكن ضمان توافق مخطط قاعدة البيانات مع النسخة السابقة دون تلك الملفات.

## الإعداد
`config.js`:
- `SUPABASE_URL`: رابط مشروع Supabase.
- `SUPABASE_ANON_KEY`: Publishable/Anon key للمشروع.

هذه النسخة لا تنفذ أي تحصيل إلكتروني حقيقي.

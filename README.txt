# المحسن ستور v3
تمت إضافة:
- login.html تسجيل الدخول وإنشاء الحساب.
- checkout.html صفحة بيانات الشحن والسلة وإنشاء الطلب.
- payment.html واجهة الدفع الإلكتروني.
- حفظ الطلبات داخل Supabase.
- order_items + shipments.
- الدفع عند الاستلام يعمل كطريقة طلب.
- الدفع الإلكتروني مجهز للربط الآمن ببوابة دفع.

ضع مفتاح Supabase Publishable/Anon في config.js.
ثم شغّل supabase.sql من النسخة السابقة.

الدفع الإلكتروني الحقيقي:
لا يتم وضع Secret Key داخل المتصفح. نحتاج في الخطوة التالية اختيار بوابة الدفع (مثل Stripe أو Paymob أو غيرها) ثم إنشاء Edge Function آمنة.
